# Progress Assessment: Beginner AI Project with Claude Code

## Purpose

This is an **individual beginner progress assessment** for DEV, SDET, QA, BA, and PM.

The purpose is to assess how well you can **delegate a small piece of professional work to Claude Code CLI**, work with the result, and demonstrate that you understand and own what you submit.

The assessment is **not primarily a test of your professional role skills**.

All roles work from the same calculator requirements in **`BRD.md`**.

---

## Common Rules

- **Claude Code CLI is mandatory.**
- Use only commands and controls already taught in Claude Code Setup.
- Complete the assessment and review within **two days**.
- The work is individual.
- You may ask colleagues for as much help as you need.
- Receiving help does not reduce your result.
- You must still be able to demonstrate, explain, inspect, and own the work you submit.
- The individual live review is decisive. Submitted files are supporting evidence.

The assessment is based on the Claude Code commands and controls taught in Claude Code Setup. Later-course techniques are not required and do not provide additional credit. Behavior that Claude Code performs automatically is not treated as a trainee skill unless it was part of the taught scope.

---

## What to Retain

Keep:

- your working folder;
- your final role-specific artifact or artifacts;
- the relevant Claude Code session, when practical.

You do **not** need to prepare complete prompt transcripts, screenshots of every interaction, Git history, or other detailed activity logs.

---

## Role Assignments

### DEV

Use Claude Code CLI to create the web calculator described in `BRD.md`.

**Deliverable**

- working calculator;
- project files needed to demonstrate it.

Perform a few representative human checks of the calculator before submission.

You are not expected to write the implementation manually. Claude Code may create most or all of the code.

---

### QA

Use Claude Code CLI to analyze `BRD.md` and prepare a manual test plan for the required calculator functionality.

**Deliverable**

- usable manual test plan.

Manual test execution is **not required**.

Claude Code may identify test conditions, propose test cases, organize them, and revise the test plan.

---

### SDET

Use Claude Code CLI to analyze `BRD.md`, propose suitable tests, and create a small meaningful automated-test subset.

**Deliverables**

- small test-analysis artifact;
- small automated-test artifact.

Automated execution through Claude Code is **not required** at this stage.

Claude Code may propose which tests to automate and may generate the automation code.

You may use automation technology that you already know and can reasonably understand. If Claude Code must make technical assumptions because no runnable reference calculator is provided, keep those assumptions visible and be prepared to explain them.

---

### BA

Use Claude Code CLI to review `BRD.md` and propose improvements.

**Deliverable**

- BRD improvement proposal containing proposed changes and reasons.

The original `BRD.md` remains the authoritative requirement source.

Claude Code may identify ambiguities, assumptions, inconsistencies, missing information, unclear wording, or other useful improvements.

---

### PM

Use Claude Code CLI to analyze `BRD.md` and prepare a compact plan for delivering the calculator project.

**Deliverable**

- one compact project-plan artifact.

Claude Code may propose activities, sequence, responsibilities, dependencies, checkpoints, assumptions, and relevant small-project risks.

Do not create multiple separate PM documents unless they are genuinely needed for your chosen plan.

---

## Live Review

During the individual review, be prepared to:

- start or resume Claude Code in the correct working folder;
- explain what work you delegated to Claude Code;
- show how the interaction developed;
- explain what Claude Code created, changed, or proposed;
- explain relevant actions or permission decisions;
- show what you checked before accepting the result;
- explain the artifact you are submitting;
- explain how you would continue the work.

If the original assessment session is not available, the Team Lead may ask you to demonstrate exit/resume using a short Claude Code session during the review.

You do not need to prove that you could have produced the same artifact without AI.

You do need to show that you understand enough to **inspect, explain, verify at an appropriate beginner level, and own the result**.

---

## Submission

Submit the required role-specific artifact or artifacts together with the working files needed for the review.

The exact submission location and deadline within the two-day assessment window will be provided separately.
